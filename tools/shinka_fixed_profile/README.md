# Fixed Shinka source preparation

Prepare the retained ShinkaEvolve v0.0.7 sources without installing, importing,
building or executing the upstream project:

```bash
python -m tools.shinka_fixed_profile \
  --archive /path/to/retained/archive.tar.gz \
  --destination /path/to/new-shinka-source-profile
```

The tool pins the complete archive before safely inspecting every member and
selecting four unchanged upstream modules. Four package initializers become
inert; a fixed Lunar entrypoint and the existing pinned Lunar broker subset make
ten Python modules. The original Apache notice and Lunar MIT notice are both
retained. The canonical source manifest is written last into a fresh directory.
Errors use fixed codes, and failed partial output is never silently reused.

The broker is generated by the same reviewed helper as the fixed OpenEvolve
profile. Shared request, memory and descriptor-file validators must remain AST
equivalent to its pinned asset, except for Shinka's solver/error labels and an
additional single Python evolve-block check. Preparation refuses source drift.

The fixed entrypoint uses actual Shinka diff prompts and search/replace helpers,
with one existing broker request and original request/memory grants. It supports
one Python evolve block and preserves all immutable bytes. It never executes the
candidate or an evaluator. The resulting `gen_0/main.py` and closed
`programs.sqlite` snapshot match the existing Shinka reader's explicit
`program_ids=['proposal']` selection. The sole row has `correct=0` and
`combined_score=NULL`; it carries no successful-evaluation claim, so default
top-k selection refuses it.

Source preparation itself produces no candidate or SQLite output. SQLite
serialization is a required, still-unaccepted native runtime dependency.
Complete runtime/build closure, sealed startup, actual upstream semantics,
original execution observation, cancellation/recovery, retained producer
evidence and production admission remain separate acceptance work. There is no
host-interpreter fallback or model/evaluator command in this tool.
