# Data model

No new durable receipt, recovery or launch authority schema. New Linux implementation
version and private command FD roles select independent supervision. Original controlv2
and all original nonce/deadline/registration/handoff/terminal/output hashes stay unchanged.

Host-only original live watcher owner retains exact Popen object, original bootstrap
pidfd, original deadline and cleanup state. It exposes no saved PID/PGID signal authority.
Ready R, finish F+EOF and acknowledgement D+EOF are bounded ephemeral byte protocol.
Actual watcher exit0/reap is necessary for clean normal outcome, not receipt content.
Historical load/recovery does not recreate this live owner or upgrade past evidence.
