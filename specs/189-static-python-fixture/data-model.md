# Data model — draft installation profile and bounded observations

Status: limited G1 pure DTO parsers are implemented, including the installation
descriptor, source/staging observations, and startup-closure comparison. Their
synthetic/provider-free validation does not by itself establish verified inputs,
a complete source import closure, a configured build, a static artifact, runtime
acceptance, or production admission. The remaining fields below are a review
model, not proof that every nested observation wire exists. Freeze exact v1
fields and bounds before adding parser behavior for a new wire. Canonical
UTF-8 JSON uses exact keys/types, sorted keys, compact separators and no NaN or
duplicate keys. Digest values are lowercase SHA-256. Reject placeholders/nulls,
unknown fields, booleans as integers, subclasses/custom collections and oversized
text/vectors before hashing, callbacks or filesystem work.

## StaticPythonInstallationDescriptor

Required scalar fields: schema_version='1';
protocol='lunar-static-python-installation-v1';
scope='installation-owned-static-frozen-fixture-only'; installation_version;
platform='linux'; architecture='x86_64'; python_version='3.13.12';
cache_tag='cpython-313'; abi_profile='cp313-release-gil';
frozen_main='_lunar_static_main';
source_tag; source_commit; source_archive_sha256; source_tree_sha256;
patch_set_sha256; recipe_sha256; toolchain_manifest_sha256;
link_manifest_sha256; initialization_profile_sha256;
frozen_inventory_sha256; builtin_inventory_sha256; alias_inventory_sha256;
artifact_sha256; artifact_size; artifact_mode; elf_profile;
execution_performed=false; runtime_load_protection=false;
production_admission=false; general_code_origin_protection=false.

Known research identifiers: source_tag='v3.13.12', source_commit=
'1cbe481834751b0125e006042ffbd8cd5eaec8a8'; observed annotated tag object=
'c3024299e68ff061b197b711368c3e1d74beb4c7'. The Git annotated-tag signature
remains unverified. The python.org detached source-archive signature was verified
separately and retained in `release-input-audit-20261021.md`, but the current
installation descriptor deliberately fixes `signature_verification="not-performed"`
and is not bound to that audit. A source Git OID is not labeled as a SHA-256 hash.
The `source_tree_sha256` domain is the canonical complete sorted source-file
inventory of path, mode, size and byte SHA-256; it is not a Git tree SHA-256.
Other manifest digests cover their exact independently retained canonical bytes. The
archive digest covers retrieved bytes; acquisition/signature evidence remains a
separate audit until an explicitly revised descriptor contract binds it.

Required bounded nested records:

- source_provenance: the model for upstream identity, annotated tag object,
  acquisition and signature evidence, source archive/tree digest, and ordered
  patch path/digest vector. The implemented descriptor currently records a
  SHA-pinned public archive declaration and fixes signature verification to
  `not-performed`; it does not prove acquisition or bind the separately retained
  detached-signature audit.
- toolchain: exact compiler/linker/binutils versions and executable digests,
  target triple, sysroot/header digest, musl source/version/patch/digest, libc/libm
  and compiler support archives. Default host packages cannot fill missing fields.
- recipe: complete compile/configure/link flags, explicit environment allowlist,
  generated configuration digest, module enable/disable disposition, link inputs
  and reproducible-build comparison result if performed. Build timestamps are
  provenance, never a replacement artifact pin.
- generator: source/recipe/executable pins, host architecture, exact CPython
  version, generated bytecode/marshal provenance and per-module generated digests.
- embedded_startup_arrays: the current profile requires this array to be empty
  and `separate_startup_code="none"`; the parser refuses nonempty arrays. A future
  profile with separate startup arrays requires an explicit contract revision.
- frozen_modules: ordered unique exact names, is_package boolean, source identity
  and digest, generated byte-array digest/size and selected table/alias membership.
- builtin_modules: ordered unique exact names, init symbol, source/object/archive
  identity and digest; includes the reviewed CPython core/bootstrap dispositions
  and `_lunar_fixture_pipe`. Extra stock modules refuse.
- aliases: complete ordered alias-to-original mapping; no unlisted stock aliases.
- initialization_profile: the implemented descriptor records fixed PyPreConfig/
  PyConfig values, loader policies, and expected startup module names. It does
  not contain actual module origins or runtime refusal observations; those belong
  to separate observation contracts and require real runtime evidence.
- elf_profile: ELF64, little-endian, EM_X86_64, ET_EXEC, no PT_INTERP or DT_NEEDED;
  the implemented descriptor parser validates a bounded format/count projection.
  It does not retain raw ELF headers, segments or dynamic entries; the separate
  artifact verifier must compare caller-retained bytes to any such claims.

Current parser-enforced ceilings include: descriptor<=256KiB, patches<=32,
frozen modules<=128, builtin modules<=128, aliases<=128, link inputs<=256,
module/label names<=128 ASCII characters, provenance strings/paths<=4096 UTF-8
bytes, artifact<=128MiB (134217728 bytes). This is the existing
`producer_launcher.MAX_OUTPUT_BYTES` / `linux_executable_binding` limit, not a
new adjustable bound; no ceiling increase or temporary exception is permitted.
Aggregate vector/text budgets must also be bounded.
These limits are comparison ceilings, not proof of input acquisition, inventory
completeness, a successful build, runtime admission, or final module counts. The
individual parsers also enforce their own fixed node/depth/text/wire budgets.

## External pins and live ownership

The runner requires independent expected_installation_descriptor_sha256,
expected_installation_version, expected_artifact_sha256, expected_target_profile,
plus the existing caller-owned launch/attestation/grant/deadline bindings. The
descriptor self-digest, installed current bytes or parsed JSON cannot invent
those external pins. An installation anchor/path is local evidence only; open
no-follow and compare original identity/size/mode/time/hash pins before copying.

Use the original sealed target object's ownership and lifetime rules. No new
public numeric-FD DTO can create an owner; no material FD or target FD survives
context exit by contract. Existing native v2 schemas and FD keep-list stay intact.
The selected original target owner must retain a private object identity/binding
and independent cleanup authority through launch/recovery, with dedicated fixture
proof; otherwise a separately reviewed owned-target recovery implementation is a
prerequisite. No such private-owner API is asserted to exist by this model. The
current public `sealed_linux_executable` numeric-FD helper closes by number and
has not established foreign-FD reuse safety. Same bytes, parsed evidence or a
reused FD number must not reconstruct the original owner or its cleanup authority.

## StaticPythonFixtureObservation

Bind installation descriptor/artifact/version/target digests, actual sealed target
identity/seals, actual Python version_info/cache_tag/flags, finite startup module
names/origins, frozen main name/result, bounded pipe transcript digest, original
ready/release/start/terminal evidence, inherited FD census and complete owned
process/FD cleanup. Distinguish machine-derived artifact facts from Python-derived
runtime observations; missing or fabricated runtime output refuses acceptance.

Only successful actual execution may set execution_performed=true and
initial_image_binding='sealed-static-installation-image'. Keep
runtime_load_protection, production_admission and general_code_origin_protection
false in all outcomes. Fixed refusal categories cover platform/profile/pin/shape,
static ELF, incomplete closure, initialization, unsupported codec/import/loader,
protocol, deadline/cancellation, source drift and cleanup_unknown; error strings
must not include source paths, credentials or arbitrary child stderr.
