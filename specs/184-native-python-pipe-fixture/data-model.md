# Evidence model

No new production DTO, input marker, read grant, capability or durable authority.
Only disposable tests describe their installed CPython path/layout, explicit fixture
read roots, original target/broker descriptors and observed Python flags/version.

Fixture evidence must identify trusted-host-fixture-only scope and explicitly false
runtime_load_protection. Observed flags/version/cache tag are compatibility observations,
not independently retained runtime content/loader/ABI admission fingerprints.
The sealed static launcher and originalv2 grant/control lifecycle retain their meaning;
subsequent interpreter/stdlib/package load bytes remain trusted host runtime bytes.

Private response fixtures contain inert request IDs and bodies only. Endpoint/headers/
credentials do not enter target configuration, argv or environment. Original process
and FD ownership remain local and ephemeral; no persisted PID is a reap/signal handle.
