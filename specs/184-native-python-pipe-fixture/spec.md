PR final CI/merge is independently tracked. This is a compatibility/acceptance fixture,
not a new production Python admission or immutable runtime capability.

and interpreter_load_binding=trusted-host-fixture-only. Dynamic CPython/loader/stdlib

request/response, allowed work/output writes, stdio capture and original FD closure

cleanup and original process reap on every path. Tests do not run arbitrary project
code, OpenEvolve/Shinka upstream, real campaigns or remote/company evaluators.

and recovery/publication schemas unchanged. No SDK extraction, archive/native loader
