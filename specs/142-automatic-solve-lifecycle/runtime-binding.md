# Registered criteria and native preparation binding

T039 keeps preregistration and native observation identities separate. Task source bytes bind to
the parent's goal; input bytes bind to the parent's complete input ledger. The resulting contract
digest, canonical input-descriptor-table digest, generated harness digest, profile bytes, semantic
pipeline digest and frozen evaluator-bundle fingerprint are independent runtime identities.

Before any independent probe runs, a read-only inspection must parse the complete registration,
verify all twenty material pins, validate the exact supported reference criteria and eight fixed
probe snapshots, and call the existing native preparation validator. A complete prepared event
and its artifact rows are required; a merely valid unfinished intake is insufficient. The
prepared contract must have exactly the registered limit input, required value output, maximize
objective with no metrics, output `valid-value` independent constraint, source `python-files`
independent count constraint with minimum two, no soft constraints, and population strategy.
Free-form names and descriptions do not change these executable declarations.

The bound receipt records both digest sets and the parent's identity. The observation manifest
continues using native contract/input-table/harness digests. It is generated from those verified
values and linked through the receipt to the preregistration; no existing observer or auditor
invariant is relaxed. A read-only binding means only `criteria_bound`, never successful
preparation or real acceptance by itself.

Independent execution runs exactly eight registered probes in fresh retained workspaces using
the actual harness and native snapshot request protocol. Full expected projections include
validity, quality, combined score and constraint code. Typed reports, canonical projections,
timeouts, exits and actual cleanup observations must be retained. Missing/unknown cleanup cannot
be upgraded to passed. Re-read the preparation and all registered material bytes after execution
before publishing a complete binding. No model call, source candidate execution, automatic retry
or repair is performed by this layer.
